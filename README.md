# Vikkypaedia Neonatal Resuscitation Module

A self-paced, role-aware learning companion based on the supplied *Textbook of Neonatal Resuscitation*, 8th edition source package.

## Open the module

**[Launch the Neonatal Resuscitation learning module](https://vikramsakaleshpurkumar-byte.github.io/Vikkypaedia-Neonatal-resuscitation-module/)**

The course runs entirely in the browser. No account, installation, backend, or external library is required. Progress and quiz answers are saved only in the learner's browser on that device.

## What is included

- 14 sequential learning units
- Nurse, undergraduate, postgraduate/resident, and faculty views
- 42 self-check questions
- Completion-gated progression
- Locally saved progress and scores
- Printable completion certificate
- Mobile-friendly and keyboard-accessible design
- Explicit source attribution for safety-critical content

## Educational notice

This independent learning companion summarizes the supplied NRP 8th-edition source and 2020-era science. It is not affiliated with or endorsed by the American Academy of Pediatrics or American Heart Association, does not confer NRP certification, and is not a substitute for an authorized course, supervised skills training, current guidelines, local protocols, or clinical judgment.

The supplied source package ends at printed page 317; the appendix and index listed in its contents were absent. Users should verify exact wording, tables, figures, and subsequent updates against authorized source material.

## Running a local copy

Download `index.html` and open it in a modern web browser. All styles, course content, interactions, saved-progress logic, and certificate functionality are contained in that one file.
